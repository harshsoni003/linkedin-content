# LinkedIn Content

My LinkedIn writing workspace. Voice profile, drafts, and published posts, version controlled.

## How it works

```
voice-profile.md   how I write — paste this into every drafting session
ideas/             raw material: wins, numbers, opinions, client moments
drafts/            posts being written and checked
published/         posts that shipped, with their results
tracker.md         what stage every post is at
```

## The loop

1. Something real happens → write it in `ideas/raw-material.md`
2. Draft it → `drafts/`
3. Check it: every fact confirmed, every machine-sounding line rewritten
4. Publish → move to `published/` and record the numbers
5. Month end: read the numbers, keep what worked

## Rules I hold myself to

- Never publish a number I can't defend in the comments
- Any missing fact stays marked `[NUMBER: what goes here]` until I confirm it
- Read it out loud before it ships
- One post, one idea
