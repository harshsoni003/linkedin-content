# LinkedIn Content

My LinkedIn writing workspace. Voice profile, drafts, published posts, and the reference material I write against.

## Layout

```
voice-profile.md      how I write — paste into every session
tracker.md            what stage every post is at

ideas/                raw material: wins, numbers, opinions, moments
drafts/               posts being written and checked
published/            posts that shipped, with their results

skills/               the 11-skill system, what each one does
reference/            post format, hook families, AI tells
```

## The loop

1. Something real happens → `ideas/raw-material.md`
2. Draft it → `drafts/`
3. Check it against `reference/ai-tells.md`
4. Publish → `published/` with the numbers
5. Month end → read the numbers, keep what worked

## Reference

- **[skills/](skills/README.md)** — the 11 skills and when to use each
- **[reference/post-format.md](reference/post-format.md)** — how a post is built
- **[reference/hook-families.md](reference/hook-families.md)** — 7 ways to open

## Rules I hold myself to

- Never publish a number I can't defend in the comments
- Missing facts stay marked `[NUMBER: what goes here]` until confirmed
- Read it out loud before it ships
- One post, one idea
- One goal per post
